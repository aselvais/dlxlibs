DlxLibs  1.0
Utilities for the Deluxe team working with the EDP in Python
Deluxe EDP libraries

This repository contains some common libraries that can be used in the EDP (CDSW).

It has to be included inside of your project using GIT Submodules: https://bitbucket.deluxe.com/scm/fmcgnew/spark-template-project.git

Setup

Adding this repository as a submodules of "yours"

git submodule add -b master https://bitbucket.deluxe.com/scm/ede/dlxlibs.git
git submodule init

Updating the submodule within your repository

git submodule update --remote
